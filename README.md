# Shard Pickaxe

A DonutSMP inspired pickaxe.

### Functionality

**Shard Pickaxe** makes that so you can mine 3x3 but when you start mining it will start as diamond pickaxe mining speed and go up every time you mine. Keep in mind it resets everytime you dont hold it.
